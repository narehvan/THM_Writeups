# TryHackMe Write-up collection
A collection of write-ups on TryHackMe challenge rooms
# How to use
- The collection is meant to be used in Obsidian (https://obsidian.md/). Although the files are all MD files and may be used by another application that can handle MD files.
- Each root directory is a single challenge.

## Install
1. Download and install Obsidian application from https://obsidian.md/.
2. Download the project from github

```bash
git clone https://github.com/narehvan/THM_Writeups.git
```

3. In Obsidian: 
	1. Manage vaults
	2. Open vault and point to the root directory of this project

## Plug-ins
Only core-plugins are used. no additional plugin is needed

## Theme
The "Border" theme (https://community.obsidian.md/themes/border) is the one used. But the files are not checked in to github so you can configure Obsidian the way you wish.

## Obsidian `app.json` settings**
```
 {
  "readableLineLength": false,
  "showLineNumber": true,
  "newFileLocation": "current",
  "attachmentFolderPath": "./",
  "alwaysUpdateLinks": true,
  "showUnsupportedFiles": true
}
```
